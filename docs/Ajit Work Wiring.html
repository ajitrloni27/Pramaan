⚠ CRITICAL — NEVER DO THIS

  • NEVER “fix” a shaky read in the OCR. Report it exactly; let the gate handle it. A confident wrong number is worse than an honest yellow box.
  • NEVER let a low_conf field auto-place a hold. It can only STAGE. A bad read must never freeze a real invoice — that is the trust model, and it’s half yours.
  • NEVER let Granite touch the numbers. Wording only. Every number in the letter comes from Murgesh’s deterministic proof cards.
  • NEVER ship a letter without the banner — “AI-generated — review before sending”. The agent prepares; the person decides.
  • NEVER let the demo path depend on a live model call. The fallback must render the same template with the same banner — if Granite is down onsite, nobody in the audience notices.
  • NEVER edit the orchestrator or the schemas. A shape problem is a contract issue → 2-minute call to Murgesh, never a silent edit.
  • NEVER add features in P9. Only break and fix. A flawless demo of 80% beats 100% that glitches.
  • NEVER crash on a blank or garbled photo. Return “unverified”. Silence over a false alarm, every time.
