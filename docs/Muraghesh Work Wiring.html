⚠ CRITICAL — NEVER DO THIS

  • NEVER put a model in the compare path (step 03). The verdict is arithmetic over cited numbers — that is the structural hallucination defense. “Let the LLM decide the gap” → the answer is no, every time.
  • NEVER weaken the two-tier hold (placed vs staged) for speed or “cool factor”. A misread must at worst stage a hold or place a 72h hold that self-heals. Permanent consequences need the tap. This is the trust model in code.
  • NEVER change a schema after P1 without a 2-min V–M sync. A schema change is a contract change — the #1 merge risk. If drift is found late, the UI bends to the engine, never the reverse.
  • NEVER copy the pipeline for the lease. Lease = rulebook swap through the SAME trunk. Copy-pasting the engine is amputating the tree (rule #10). Stop anyone who tries.
  • NEVER let anyone else merge into services/brain — and a PR touching packages/contracts needs you AND whoever consumes the changed field.
  • NEVER crash on a step error. Append an “error” audit event, mark affected cards “unverified”, return a partial RunResponse.
  • NEVER put timestamps in the seeded payload. Byte-identical or the demo gamble returns — the stage flow must never depend on live OCR/LLM/network.
  • NEVER inline a type. If the app or the brain wants a shape, it lives in packages/contracts and gets imported.

The WHY Behind the Key Decisions

  • Compare is deterministic: arithmetic over cited numbers can’t hallucinate; a model in the verdict path could “think” a gap that isn’t there.
  • Hold is two-tier: an autonomous action must be safe — worst case is a staged hold or a 72h hold that self-heals.
  • MCP, not direct calls: 2026 tool-discovery standard; watsonx.data ships a managed server (judge bait); keeps the rulebook server-authoritative.
  • Freeze schemas P1: frontend builds against a mock and never blocks on backend — the most important scheduling decision in the sprint.
  • Seeded mode: the demo is a rehearsed script, never a gamble on live OCR/LLM/network in 90 seconds.
  • Mock gateway: real APIs would eat the sprint; the mock makes ACT real (state mutation) and demoable, honestly — narrate real integrations as the production path.
