⚠ CRITICAL — NEVER DO THIS

  • NEVER make up a number. No clean official source → write “SOURCE NOT FOUND” → the card says “check with a person.” A made-up number is a lie; the whole product is “prove, don’t guess.”
  • NEVER write “approximately ₹X.” Exact value + unit, or UNVERIFIED. There is no third option.
  • NEVER ship a RuleRow without match_terms[]. lookup_rule matches on them — a thin list means the rule is silently never found, and the card never appears. Silence where proof should be.
  • NEVER rename a RuleRow field after P1. The schema is frozen — it is Murgesh’s contract. A shape problem is a 2-minute V–M sync, not a surprise edit.
  • NEVER let the trap value drift. The planted official number (₹2) must stay byte-exact with Vrajesh’s signed-off spec — the deterministic demo depends on it.
  • NEVER let an unsourced number reach the screen or the deck. Citation gate: the team waits 10 minutes for a correct citation rather than demo a wrong number. Manas has veto power here — use it.
